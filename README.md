### 🧠 En qué trabajo

- **Agentes y RAG en Amazon Bedrock:** Bedrock Agents con herramientas en Lambda, Knowledge Bases sobre Amazon S3 Vectors y la API Converse con un modelo de respaldo.
- **IA para operaciones y seguridad:** un ingeniero de guardia que diagnostica alarmas y propone el rollback para que una persona lo apruebe, y un centinela que detecta configuraciones inseguras y las cierra solo.
- **Infraestructura como código:** Terraform y CloudFormation, desplegados desde AWS CloudShell.
- **RAG sobre repositorios para QA,** en Lambda con contenedores: [qa-agent-core](https://github.com/AndresDFX/qa-agent-core).
